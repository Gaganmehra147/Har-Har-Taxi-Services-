# 🚖 Har Har Taxi Services - Jabalpur

> Premier private cab & taxi booking service in Jabalpur, Madhya Pradesh. Offering 24x7 local, airport (Dumna JLR), railway station transfers, and outstation trips across MP with clean AC cars and verified drivers.

---

## 🌟 Key Features

- **24x7 Instant Taxi Booking:** Seamless WhatsApp & direct phone booking integration.
- **Fleet Options:**
  - White Maruti Suzuki Swift Dzire (4-Seater Sedan)
  - Maruti Ertiga (6-Seater SUV)
  - Toyota Innova Crysta (7-Seater Premium SUV)
- **Top Outstation Routes:**
  - Jabalpur to Kanha National Park
  - Jabalpur to Bandhavgarh Tiger Reserve
  - Jabalpur to Bhedaghat Marble Rocks & Dhuandhar
  - Jabalpur to Pachmarhi Hill Station
  - Jabalpur to Khajuraho Temples
  - Jabalpur to Bhopal, Indore, Rewa, Maihar & Amarkantak
- **100% Mobile Responsive:** Optimized for iPhones, Android phones, and tablets with sticky quick-action bar (`Call Now`, `WhatsApp`, `Book Taxi`).
- **SEO Ready:** Complete metadata, OpenGraph, JSON-LD Schema (LocalBusiness, TaxiService, FAQs, Breadcrumbs), XML sitemap, and robots.txt.

## 🚀 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/Gaganmehra147/Har-Har-Taxi-Services-.git
cd Har-Har-Taxi-Services-
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production:
```bash
npm run build
npm start
```
